# pairwise-crafting-graph

合成一把剑需要矿石，矿石的配方又要一把剑，点了合成后材料扣了但产物没出，批量合成把库存扣成负数：配方图没有环检测，深度优先递归直接栈溢出；拓扑排序按配方 ID 而不是依赖层级，前置产物还没算就扣材料；替代配方按顺序试，第一个失败后已扣的中间材料没回滚；批量合成按目标数量一次扣总材料，实际受工作站产能限制，扣多了不退；共享材料被多个配方同时预留，两个合成任务都通过校验但只有一个能完成；数量取整用四舍五入，半份材料被算成一份；副产物没有回填库存，连续合成后副产物消失；配方缓存按等级存，角色技能提升后仍用旧成功率；工作站等级只校验最终产物，中间步骤用了更高级工作台；异步合成完成顺序和扣料顺序不一致，取消任务后材料对不上；递归深度没有上限，长配方链把主线程卡住；UI 预检查和服务端结算用两套配方表，显示可合成但服务端拒绝；回滚只回滚最终产物，已消耗的燃料和时间没退。gameplay/crafting_graph.py 是核心，tests/test_crafting_graph.py 15个红。要修的是：环检测；拓扑顺序；替代回滚；批量扣料；材料预留；取整规则；副产物；缓存失效；工作站层级；异步顺序；递归上限；前后端同表；完整回滚。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
